# 開発の進め方

2026-09-09 時点。月白しずくを普段の作業のそばに置けるアプリへ育てる。一つの操作を実装し、実際の Windows 上で確かめてから次へ進む。既存の対話・謎解きアプリには変更を加えない。

## 現在の区切り

透明表示、隠す・戻す・終了、画面外からの復帰に加え、明示的に始める「しずくをつかんで移動」を実装した。移動中はポーズを止め、透明な余白を背後へ通す。ボタンを離すと移動を終え、普段のクリック透過へ戻る。

この PC の実マウスでは、しずくが右へ 26・下へ 41 ピクセル動き、移動モード中の透明な余白から背後のボタンも押せた。一方、ドラッグ後に元の入力アプリの焦点が外れる結果があり、日常利用に適する操作として完成とはしない。利用者の手元での確認も依頼中。検査結果と未確認の範囲は [検証記録](evaluation.md) を参照する。

## 次に進む順番

| 順番 | 作業 | この区切りで確かめること |
| --- | --- | --- |
| 1 | 移動後の焦点と常駐の安定性 | ドラッグ後の入力先、取り消し、連続操作、トレイの手操作を確認する。一定時間表示を続けて負荷を再測定し、非表示・終了・スリープ復帰も確かめる |
| 2 | 大きさと普段の居方 | 画面端で邪魔にならないサイズ調整を先に扱う。その後、小さな視線や頷きの頻度を試し、作業中に気になる動きがないか評価する |
| 3 | 呼んだときの短い反応 | 利用者の操作で呼び、こちらを向いて応じる。入力を始める入口と閉じる操作を整え、大きな会話画面を常時置かずに使えるか確かめる |
| 4 | 既存の会話・音声を接続 | 既存アプリから必要な部分だけ選び、まずテキスト、その後に音声を一つずつ接続する。応答待ち・中止・失敗からの復帰、キーの管理、費用を確認する |
| 5 | 明示的に共有した画像と小さな遊び | 利用者が選んだ画像だけを一緒に見る入口を作る。小さな遊びは通常の常駐や会話を邪魔しない形で別に試す |

サイズ調整と動き、テキストと音声も同時には追加しない。まず一つを動かし、その検証結果を見て次の具体的な作業を決める。以前の表示中メモリ約 494 MiB は移動機能追加前の短時間計測であり、今後の軽量化の成果には数えない。

## 後で判断するもの

複数モニター、ウィンドウの縁への着座、窓の間の移動、インストーラーと更新方法は、主画面での常駐が安定してから扱う。独自の外見を制作する場合は、現在の検証用モデルと分けて利用・配布条件を決める。

今回、新しい AI API、課金契約、常時送信、自動起動は追加していない。新しい GitHub リポジトリも作成しておらず、公開範囲は未決定。作成時は Private を初期案とし、Public 化は確認する。

Notion への反映案は「独立アプリの透明常駐に、明示的な直接移動を追加。移動後の焦点と長時間評価を継続。会話・音声接続は未着手」。Notion 自体の更新は行っていない。
