# 開発の進め方

2026-09-09 時点。月白しずくを普段の作業のそばに置けるアプリへ育てる。一つの操作を実装し、実際の Windows 上で確かめてから次へ進む。既存の対話・謎解きアプリには変更を加えない。

## 現在の区切り

透明表示、隠す・戻す・終了、画面外からの復帰に加え、明示的に始める「しずくをつかんで移動」、3段階の大きさ調整、端末内の「呼ぶ」反応を実装した。移動中はポーズを止め、透明な余白を背後へ通す。ボタンを離すと移動を終え、普段のクリック透過へ戻る。

以前の実マウス検証では、しずくが右へ 26・下へ 41 ピクセル動き、移動モード中の透明な余白から背後のボタンも押せた。一方、ドラッグ後に元の入力アプリの焦点が外れる問題は継続しており、日常利用に適する操作として完成とはしない。直接移動は利用者が明示的に始める形を保つ。

大きさは操作窓・トレイから「小」「標準」「大」を選べる。下辺中央を基準に変更し、画面端で補正する。隠したままの変更、選択の保存・再起動、サイズを保った位置復帰、古い設定の移行を Electron の検査で確認した。実マウスでは操作窓の「小」を選んで縮小できた。「標準」「大」の手操作、サイズ変更後の実ドラッグは未確認。検査結果と未確認の範囲は [検証記録](evaluation.md) を参照する。

「呼ぶ」は `Ctrl + Alt + Shift + C`、トレイ、操作窓から始める。隠していれば再表示し、約 2.1 秒の小さな頷きと、対応するモデルで控えめな表情変化を返す。連打は積まず、隠す・移動・モデル再読み込みで取り消す。OS の「動きを減らす」では静的な表情だけにする。これらの終了・復帰・取り消しを Electron の検査で確認した。AI・音声・録音は接続していない。実マウスや物理ショートカットでの入力先の維持、主観的な自然さの評価は残っており、Electron 上の機能検査と分けて扱う。

WebGL（GPUで描く仕組み）が一時的に止まったときの停止・復旧処理を実装し、模擬検査10項目を完了した。モデルと画像を保持し、呼びかけ・移動を取り消して復旧を待つ。待機中のC/Mに対応する処理から操作窓を開かず、非表示中に復旧しても追加描画0、動きを減らす設定では1フレームだけ描いて止まることを確認。モデル再読込や読込失敗との組合せ、停止中の終了と残留プロセスなしも確認した。復旧後の全身と服・髪はキャンバス画像で目視済み。実際のスリープ復帰やGPU障害、別アプリへの実入力は別の確認項目で、今回も物理キー検査は行っていない。

## 次に進む順番

モデル再読込時の画像解放を修正した`f71bc0d`では、実画像で古い画像の解放と新モデルの保持を確認し、表示5分・非表示1分・呼ぶ／表示切替／サイズ変更15回を完走した。表示中の平均はCPU約1.05%、メモリ約482MiB。非表示CPUは計測経路による差が残るため条件ごとに記録する。この計測はWebGL復旧処理追加前の結果であり、現行版の数時間の安定性を確認したものではない。

| 順番 | 作業 | この区切りで確かめること |
| --- | --- | --- |
| 1 | 残っている操作・常駐確認 | WebGL停止・復旧の模擬検査を完了。次は呼びかけ・ドラッグ後の入力先、「標準」「大」とトレイの手操作、サイズ変更後の移動、数時間常駐、計測処理の影響、実際のスリープ復帰を確認する |
| 2 | 普段の居方と反応の自然さ | 呼びかけの頷き・表情・戻るまでの間、普段の小さな視線や頷きの頻度を評価し、作業中に気になる動きを調整する。入力を始める入口と閉じる操作を整え、大きな会話画面を常時置かずに使えるか確かめる |
| 3 | 既存の会話・音声を接続 | 常駐と日常の操作を整えてから、既存アプリの必要な部分だけ選び、まずテキスト、その後に音声を一つずつ接続する。応答待ち・中止・失敗からの復帰、キーの管理、費用を確認する |
| 4 | 明示的に共有した画像と小さな遊び | 利用者が選んだ画像だけを一緒に見る入口を作る。小さな遊びは通常の常駐や会話を邪魔しない形で別に試す |

大きさ調整を検証してから「呼ぶ」反応へ進めた。次は長時間常駐・入力の焦点・日常の使い心地を整え、その後に既存の会話を接続する。テキストと音声を同時には追加せず、一つを動かして検証結果を見てから次へ進む。以前の表示中メモリ約 494 MiB は移動・サイズ調整・呼びかけ反応の追加前の短時間計測であり、今後の軽量化の成果には数えない。

## 後で判断するもの

複数モニター、ウィンドウの縁への着座、窓の間の移動、インストーラーと更新方法は、主画面での常駐が安定してから扱う。独自の外見を制作する場合は、現在の検証用モデルと分けて利用・配布条件を決める。

今回、新しい AI API、課金契約、常時送信、自動起動は追加していない。新しい GitHub リポジトリも作成しておらず、公開範囲は未決定。作成時は Private を初期案とし、Public 化は確認する。

Notionへの今回の反映案は「WebGLの一時停止中に処理が続く問題を修正。モデル保持・操作制限・再読込との組合せを含む復旧検査10項目と復旧画像の目視を完了。通常設定を維持し、終了後の残留プロセスなし。実際のスリープ復帰、数時間常駐、入力焦点は未検証／未解決として維持し、以前の5分表示の記録と区別する」。会話・音声、窓の縁への着座、独自VRMは未着手。Notion自体の更新は行っていない。
