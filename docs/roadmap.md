# 次の開発と確認

このアプリは、Windows x64・主画面1枚・手動起動を対象とした技術試作です。安定した配布版ではありません。機能を増やす前に、普段の作業を邪魔しないことと、隠す・戻す・終了する操作を重視します。[完成基準](product-quality.md)

## 近い順番

1. 利用者が自分のPCで[実使用チェック](user-check.md)を行い、VRM選択から終了までの操作、日本語IME、他アプリの入力先、トレイからの復帰を確かめる。
2. 実スリープ／画面ロック、長時間常駐、別のVRMや別PC・複数画面で再現性と負荷を調べる。
3. 直接ドラッグ後の焦点問題と、数百MiBのメモリ負荷を改善する。操作の安全性を優先し、根拠のない自動復帰は追加しない。
4. 専用の外見・音声の利用条件と、声や反応の自然さを人が評価する。モデル・音声の権利はソースのMIT Licenseと分ける。
5. 必要になった段階で、インストーラー、署名、更新、複数画面対応を検討する。現時点で完了を主張しない。

過去の測定と現在の再実行可能な検査は[検証範囲](evaluation.md)、構成と判断は[技術紹介](portfolio.md)を参照してください。
