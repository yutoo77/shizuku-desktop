## 公開前に決めること

1. **Public化の許可。** 現在はPrivate。既存アプリの公開許可は適用しない。
2. **ソース全体のLICENSE。** 候補はMIT。著作権・ライセンス表示を残す条件で、商用利用・改変・再配布を認める。モデルや音声の権利を一緒に付与するものではない。採用は未決定。[MITの説明と本文](https://choosealicense.com/licenses/mit/)
3. **CIの初回実行と自動起動。** Privateの残り無料枠と超過時の設定は取得できていない。判断前は手動設定のまま維持する。[検査と料金条件](ci.md)
4. **コミット作者のメール表示。** 現在の全履歴には、GitHubの匿名用ではないGmailアドレスが入っている。既存の公開アプリの直近commitと同じだが、このアプリのPublic化へ許可を流用しない。公開前にGitHubの匿名メールへ置換する案を確認する。履歴の書き換えはまだ行っていない。

## 試作として明示する制限

会話は定型返答のみで、外部AIと音声は未接続。モデルは利用者が別途用意する。直接ドラッグ後に入力先が外れる問題、実スリープ復帰、数時間常駐、別PC・他VRM・複数画面の確認が残る。会話窓を追加した版のCPU・GPU・メモリは未測定で、以前の数値を新しい版の性能として示さない。
