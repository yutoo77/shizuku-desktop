# ふぁるるくんの実使用チェック

最初は「いつもの作業を邪魔しないか」を15〜20分ほど確かめる。声・休止復帰はその後でよい。自動検査の代わりに同じ操作を大量に繰り返す必要はなく、引っかかった場面を教えてほしい。

## 起動と、困ったときの戻り方

このPCの開発環境では、PowerShellで次を実行する。

```powershell
Set-Location -LiteralPath "$env:USERPROFILE\Documents\Codex\shizuku-desktop"
npm start
```

選択済みのモデルが出れば準備完了。未選択なら小窓の上の「VRMを選ぶ…」で、利用条件を確認済みのモデルを選ぶ。モデルを別の場所へ移した場合は、時計の近くの月アイコンを右クリックして選び直す。アイコンは「^」の中にあることもある。新しいPCへの導入は[README](../README.md#起動する)を参照する。

以下で使う **S / R / C / M / W / Q は、すべて Ctrl + Alt + Shift と同時押し**。

- **S**：隠す／戻す。
- **R**：見失ったら画面端へ戻す。
- **Q**：アプリを終了する。月アイコンが消え、起動したPowerShellが入力待ちへ戻ることを確かめる。
- キーが効かなければ月アイコンの右クリックから同じ操作を選ぶ。操作用の小窓の×は、その小窓だけを閉じる。

## まず確かめる5項目

メモ帳などで、保存不要の短い確認文を用意する。研究資料や私的な文章を使う必要はない。

| 順番 | やること | 合格の目安 |
| --- | --- | --- |
| 1. そばで入力 | しずくを表示したまま、背後の窓をクリックして日本語を入力・変換する。透明な余白と、しずくに重なる位置の両方で試す | クリックが届き、入力先が勝手に変わらない。しずくが画面の端で欠けない |
| 2. 移動・取消 | 入力欄にカーソルを置き、M→マウスボタンを押さずに移動→Mで確定。入力欄をクリックし直さず、続きを入力する。もう一度Mで移動し、今度はEsc | 確定後も同じ欄へ入力できる。Escでは開始位置へ戻る。Rでも画面端へ戻せる |
| 3. 呼んで戻る | 入力中にC。まず元の欄に続きを入力してから、会話窓をクリックする。「定型返答」のまま日本語を変換し、Enterで変換確定、もう一度Enterで送る。会話を閉じ、Cで再び呼ぶ | 呼ぶだけでは入力先が移らない。変換確定だけでは送信されない。新しい会話は履歴なし・声オフ |
| 4. 窓に座る | 普通の窓を小さくし、上に全身が入る余白を空ける。その窓をクリックしてW。窓を手で動かす→最小化→戻す→閉じる | 縁について動き、最小化中は隠れる。戻すと再表示し、閉じると追従を解除して画面端へ戻る |
| 5. 日常の流れ | Sで隠す・戻す。月アイコンのダブルクリックと右クリックメニューも試す。そのまま普段の作業を10分ほどして、最後にQ | 素早く隠せる。意図しない窓や音が出ない。見た目・ファン音・反応の重さが気にならない。正常終了できる |

「直接ドラッグ（試験中）」は、別アプリの入力先が外れる既知の問題がある。まずはM移動で普段使いを評価する。直接ドラッグも試した場合は、操作直後に入力欄をクリックし直す前の状態を記録する。入力先を戻すためにクリックした後の成功とは分ける。

## 次に、声と休止復帰

**声は定型返答から試せる。** [音声の手順](voice-dialogue.md)に沿って自分でVOICEVOXを起動し、会話の「…」→「声で話す」をオンにして短文を送る。音量・話す速さ・声が出るまでの待ち時間・口の動きについて、気になったものだけ教えてほしい。再生中に「中止」、会話を閉じる、Sで隠す操作も試し、止まった音声が後から再開しないことを確かめる。しずくを終了してもVOICEVOXは別に残るため、自分で終了する。

実AIとの会話も試す場合だけ、[AI会話](ai-dialogue.md)の手順で接続先を選ぶ。従量課金があるので、最初は短い2〜3往復でよい。APIキーはチャットや検証メモに貼らない。「作業を一区切りした」「少し休憩する」など、私的な情報を含まない文章で十分。

**休止復帰は作業を保存してから、自分の都合のよいときに行う。** 表示した状態でWindowsをロックして戻る。次に手動でSを押して隠した状態でも試す。表示していたしずくは戻り、手動で隠した場合は隠れたまま、古い会話や声・窓選択が復活しないことを確かめる。スリープと復帰も別に1回試す。追従は解除される仕様なので、復帰後はWで選び直す。実PCのロックとスリープは自動検査では実行していない。

気になる点がなければ、後日30〜60分ほど普段の作業に置いてみる。動きを休めた状態と動く状態を別々に試すと、邪魔さや負荷の違いを判断しやすい。別PCの検証はこの最初のチェックを直してから進める。

## 返してほしい内容

この形で短く返せばよい。全部に回答できなくても、未確認と書けば次へ引き継げる。

```text
1 入力：OK / 気になる / 未確認
2 移動：OK / 気になる / 未確認
3 会話：OK / 気になる / 未確認
4 窓への着座：OK / 気になる / 未確認
5 隠す・戻す・終了：OK / 気になる / 未確認
声：気になった点 / 未確認
ロック・スリープ：結果 / 未確認
普段そばに置いた印象：
```

問題があったら「使っていたアプリ名」「押したボタンやキー」「実際に起きたこと」「S・R・Qで戻れたか」を添える。画面画像や作業内容の共有は必須ではない。必要になった場合も、しずくの部分だけでよい。

現在のモデルは技術確認用で、専用のしずくの外見は別途決める。今回の合否は入力・配置・止め方・会話の流れについて判断し、モデルの好みと混同しない。
